# Astah UML Print Studio - Diagramas de Máquina de Estados

Aplicação web desenvolvida para reproduzir de forma 100% fiel a interface gráfica e o estilo visual dos diagramas gerados no software **Astah UML Desktop** (amarelo pastel oficial `#ffffcc`, fontes Arial regulares, moldura externa `stm`, linhas e setas pretas sólidas de 1px `crispEdges`).

## Conteúdo do Projeto

- **Exercícios 1 a 11**: Diagramas completos de Máquina de Estados UML baseados nos enunciados da lista de Análise e Modelagem de Sistemas.
- **Modo Print (Tela Limpa)**: Oculta a barra de ferramentas para permitir a captura de prints perfeitos com a tecla de atalho do Windows (`Windows + Shift + S`).
- **Exportação em Alta Resolução**: Botões para **Baixar PNG** em alta resolução e **Copiar Imagem** direto para a área de transferência.
- **Painel Lateral com Enunciados**: Detalhamento textual de cada cenário e justificativas técnicas escritas.

## Como Executar

Abra o arquivo `index.html` em qualquer navegador web ou sirva através de um servidor HTTP local:

```bash
# Executando via Python
python -m http.server 8123

# Acesse no navegador:
# http://localhost:8123/tah/index.html
```
